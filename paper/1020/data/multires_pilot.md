# Multi-resolution denoising steps — training-free pilot (10/20, GPU 5, 14B FP8 + Sage + ring KV window 18, 832x480-class grids, 13 chunks x 3 latent frames)

Code: `lingbot-world-v2/specwm/multires_pilot.py` (generation, timing, decode, sharpness, rel-L2), `paper/1020/multires_analysis.py` (judge, tables, figure, videos). Latents: `specwm_out/multires/<arm>/<scene>_s<seed>/lat.pt`; clips `specwm_out/multires/judge/<arm>_<scene>_s<seed>.mp4`; judge cache `data/multires_vlm.json`.

Arms: **T** = archived 14B 4-step reference (paths2/K0_uniform4P_fx, act_spec2 code path); **full4** = the same 4-step schedule rerun in this code path (= same-config floor for rel-L2 and the judge); **full2** = 2-step full-res, nodes (0,500) = sigma 1 -> 0.833 (NOT the archived `inject/14b_2step` clips, which use nodes (0,250)); **mr4** = 4-step with steps 1-2 at the half grid, 3-4 full; **mr4b** = step 1 only at the half grid; **mr2** = 2-step (0,500) with step 1 at the half grid. Half grid = round(h/4)*2 x round(w/4)*2 (58x106 -> 28x52, 56x108 -> 28x54, 58x104 -> 28x52). The half-res step attends to a separate half-res K/V cache rebuilt from every committed chunk (bilinear-antialias downsample + clean t=0 commit, the 'lo-commit' column); x0 route: the half-res x0 prediction is bilinear-upsampled and re-noised with the same full-res noise draw the reference uses. 5 scenes x 3 seeds = 15 clips per arm.
